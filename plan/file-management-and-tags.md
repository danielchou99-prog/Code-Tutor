# Code Tutor 檔案管理與自訂標籤計畫

- 文件狀態：程式實作完成，等待 Supabase migration 與雲端驗收
- 最後更新：2026-08-09
- 使用技術：Supabase PostgreSQL、Row Level Security、Next.js Client Components

## 一、目標

把目前只有示範外觀的「檔案」頁，完成為登入使用者可以實際使用的第一版檔案管理功能。每位使用者能建立自己的資料夾與 C++ 專案、進入資料夾、保存各專案的程式碼，並在資料夾或專案加入多個 `#標籤`。

標籤規則沿用題目搜尋：看到 `#` 就視為標籤，例如 `#APCS中高級 #二分搜` 代表兩個標籤；搜尋多個標籤時採 AND 規則，項目必須同時具備全部標籤才會出現。

## 四、驗收方式

1. 登入後能建立資料夾，重新整理後仍存在。
2. 能在資料夾內建立專案，並透過麵包屑返回根目錄。
3. 建立或編輯項目時可輸入 `#APCS中高級 #二分搜`，卡片顯示兩個標籤。
4. 搜尋兩個標籤時，只顯示同時符合兩者的項目。
5. 不同專案的 `main.cpp` 內容互不影響。
6. 登出後不顯示原使用者的檔案；另一帳號也無法取得這些資料。

## 六、風險與後續方向

- 免費 Supabase 專案仍有容量與流量限制，但目前文字型 C++ 專案足以使用。
- 第一版先保存單一 `main.cpp`；多檔案專案會在後續另外規劃資料表與編輯器分頁。
- 刪除資料夾會連帶刪除其子資料夾與專案，因此介面必須先要求確認。
