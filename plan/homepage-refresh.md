## 一、目標

將目前只有歡迎文字的首頁改成完整的產品入口。新使用者進入網站後，能立即知道 Code Tutor 可以做什麼、如何開始，以及可以前往檔案或題目頁進行下一步。

首頁維持現有深色、青色重點色、細線框與 Code Tutor 專案名稱，不改動已完成的頂端導覽配置。

## 四、驗收方式

1. 點擊「首頁」後會看到完整首頁，而不是只有置中的歡迎文字。
2. 主要按鈕可以前往「檔案」，次要按鈕可以前往「題目」。
3. 首頁介紹的功能與網站現有功能相符。
4. 切換繁體中文與英文後，新增文字會正確切換。
5. 手機寬度下內容依序排列，按鈕與卡片不超出畫面。
6. Frontend lint、TypeScript 與 production build 全部通過。
