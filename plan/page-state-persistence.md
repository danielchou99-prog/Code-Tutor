# 全站頁面與進度保存計畫

## 目標

讓使用者重新整理、切換網站頁面、關閉分頁後再開啟時，能回到原本使用的位置並保留尚未完成的進度。保存範圍包含目前頁面、選取項目、表單草稿、編輯器內容與介面配置；敏感資料、登入權杖、AI 金鑰、隱藏測資與管理員參考解答不得存入一般瀏覽器狀態。

## 目前狀態

- [x] 部分程式碼草稿、設定與登入狀態已有獨立保存機制。
- [x] 網站目前頁面與頁面內選取狀態已接上統一保存。
- [x] 主要 React 元件切換後可從安全的本機狀態恢復。
- [x] 題目管理會保存公開題意草稿，隱藏測資刻意不保存。
- [x] 已建立版本、大小限制、損壞資料復原與跨帳號隔離規則。
- [x] 題目管理在快速輸入後立刻切頁時，已增加「離開前強制保存」保護。

## 執行步驟

- [x] 1. 盤點所有頁面與可遺失狀態。
  - 簡易說明：列出首頁、檔案、專案編輯器、題庫、解題器、設定及題目管理的頁面位置、選取內容、輸入與布局狀態。
- [x] 2. 建立統一且有版本的瀏覽器狀態工具。
  - 簡易說明：每份資料包含版本、使用者範圍與更新時間；格式損壞或版本過舊時安全回到預設值，不讓整個網站無法開啟。
- [x] 3. 保存目前頁面與頁面內導覽。
  - 簡易說明：重新整理後回到首頁／檔案／題目／設定等原頁；問題詳情、專案與設定分類也保持相同。
- [x] 4. 保存一般表單與搜尋篩選。
  - 簡易說明：搜尋文字、標籤、難度、狀態、語言、輸入模式與尚未送出的安全表單內容，在切頁後不被清空。
- [x] 5. 保存編輯器與 Console 工作狀態。
  - 簡易說明：保留目前專案、檔案、未儲存程式碼、stdin、Console 模式、分隔線與捲動位置；現有離頁警告仍保留。
- [x] 6. 保存題目解題進度。
  - 簡易說明：保留目前題目、語言、程式碼草稿、輸入內容與面板配置；Judge 結果可保存摘要，但不保存隱藏測資。
- [x] 7. 保存設定與管理員草稿。
  - 簡易說明：一般設定沿用既有保存；題目管理未儲存草稿使用管理員與題號隔離，且只保存公開題意表單，不保存隱藏測資、預期輸出或任何 Secret。
- [x] 8. 加入完成送出與安全清除規則；密碼及金鑰欄位從未加入保存。
  - 簡易說明：登出時清除帳號專屬暫存；成功儲存後移除對應草稿；提供安全的「清除本機進度」功能。
- [x] 9. 完成 ESLint、TypeScript 與 production build 自動檢查。
- [ ] 10. 使用者逐頁進行登入狀態下的瀏覽器驗收。

  - 簡易說明：React 的背景保存可能還沒執行就被切頁卸載，因此額外在離開元件前，把最新公開題意同步寫入安全草稿。
  - 簡易說明：逐頁驗證重新整理、切走再返回、關閉再開啟、不同帳號登入與損壞 localStorage 都不會造成狀態錯亂。

## 驗收方式

- [ ] 在每個主要頁面重新整理後，仍停留在同一頁與同一項目。
- [ ] 切換到其他頁面再返回，搜尋、選項、表單與未儲存程式碼仍存在。
- [ ] 關閉並重新開啟瀏覽器分頁後，可恢復最近一次安全進度。
- [x] 不同帳號使用不同的本機狀態鍵，不會讀到彼此的頁面草稿。
- [x] 登出會清除本次新增的帳號專屬頁面狀態，且從未保存密碼或 API Key。
- [x] localStorage 內容損壞、過大或版本不相容時，自動回到安全預設值。
- [x] AI Key、Supabase token、隱藏測資、預期輸出與參考解答不會進入此保存機制。
- [x] ESLint、TypeScript 與 production build 已通過；現有元件介面相容。

## 需要使用者手動操作的事項

- [ ] 實作完成後，依驗收清單逐頁操作一次「輸入內容 → 切頁 → 返回 → 重新整理」。
- [ ] 確認公用電腦是否希望登出時連同所有非敏感草稿一併清除；第一版預設會清除帳號專屬暫存。

## 安全原則

- localStorage 只能保存可接受留在使用者裝置上的資料。
- 登入權杖繼續交由 Supabase SDK 管理，不複製到自訂狀態。
- AI 金鑰、資料庫 Secret、隱藏測資、標準輸出與參考解答永不存入一般頁面狀態。
- 恢復資料前先驗證型別、版本、大小與所屬使用者，失敗就捨棄。
