# 題目管理空白內容與標籤切換暫存計畫

## 目標

讓管理員可以保存尚未填完的題目，不因空白題名、段落、格式、範例或配分群組文字而失敗；切換 Chrome 標籤頁時，立即保存包含空白動態欄位的公開題目草稿。

## 目前狀態

- [x] 已確認前端會把一般公開草稿寫入 localStorage，但尚未監聽 `visibilitychange` 與 `pagehide`。
- [x] 已確認後端 `LocalizedText` 與翻譯 API 會拒絕空白文字。
- [x] 已確認 Supabase 標籤代碼是主鍵，空白或未完整標籤不能直接寫入正式標籤資料表。
- [x] 隱藏測資、預期輸出、Generator 與參考解答依既有安全規範不得寫入一般瀏覽器狀態。

## 執行步驟

- [x] 1. 允許題名、摘要、題意段落、輸入輸出格式、範例與配分群組文字留白後儲存。
  - 簡易說明：管理員可以先保存半成品，不必一次填完所有文字。
- [x] 2. 翻譯時跳過空白中文欄位，英文欄位保留空白。
  - 簡易說明：沒有內容就不呼叫 AI 翻譯，也不讓空白欄位阻止其他內容更新。
- [x] 3. 未填完整的標籤保留在編輯器與本機草稿，但不寫入正式標籤資料表。
  - 簡易說明：資料庫不能接受空白主鍵；標籤填完整後，下次儲存才正式寫入。
- [x] 4. 不完整題目強制維持未發布。
  - 簡易說明：允許保存不代表要公開，避免學生看到空白題目。
- [x] 5. 監聽 `visibilitychange` 與 `pagehide`，同步保存最新公開題目草稿與空白動態欄位。
  - 簡易說明：切換 Chrome 標籤頁或分頁進入背景時，不等待 React 後續排程才保存。
- [x] 6. 補上自動測試並執行 backend tests、lint、TypeScript 與 production build。
  - 簡易說明：確認放寬空白內容不會破壞題號、標籤主鍵、配分總和與公開題庫安全。

## 驗收方式

- 新增空白段落、空白範例及空白標籤後切換 Chrome 標籤頁，再返回或重新整理，欄位數量與空白內容仍存在。
- 使用有效題號、100% 配分，但其他公開文字留白時，可以儲存為未發布題目。
- 空白或未完整標籤不造成儲存錯誤，也不會寫入正式標籤資料表；填完整後可以正常儲存。
- 完整題目仍可翻譯、儲存與發布。
- localStorage 不包含隱藏測資、預期輸出、Generator、參考解答或 Secret。

## 需要使用者手動操作的事項

- [ ] 實作完成後，在 Chrome 新增空白標籤、段落與範例，切換到另一個瀏覽器標籤頁再返回並重新整理驗收。
- [ ] 驗證一題未完成題目可儲存但不會出現在公開題庫。
