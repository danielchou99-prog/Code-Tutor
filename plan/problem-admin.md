# 題目管理後台計畫

## 目標

建立只有管理員能使用的題目管理後台，讓題目、雙語內容、標籤、範例、限制、配分群組與隱藏測資都能從網站維護，不必直接修改 SQL。同時把現有四題改成故事型正式題名，而不是把解題方法直接當作名稱。

- [x] 已用後端 UUID 白名單區分管理員與一般使用者。

## 驗收方式

- [x] 未登入與一般登入者無法使用管理 API；入口公開顯示，但非管理員只會看到權限說明，無法載入隱藏測資或修改題目。
- [x] 管理 API 能載入四題完整資料，包含隱藏測資，但頁面不顯示任何 Secret（資料層與自動測試已通過）。
- [ ] 新增或修改題目後，Problems 頁重新整理即可看到正式內容。
- [x] 配分不等於 100%、沒有測資、題號格式錯誤或欄位空白時會阻止儲存；同題號會更新既有題目而非建立重複資料。
- [ ] 發布中的題目可作答；未發布題目不會出現在一般題庫。
- [x] 四題顯示故事型正式題名，而不是演算法或解法名稱（已唯讀確認 Supabase 正式資料）。

## 需要使用者手動操作的事項

- [x] 實作完成後，在 Supabase SQL Editor 執行本階段 migration。
- [x] 將自己的 Supabase User UUID 加入後端管理員白名單；設定工具不會顯示或修改其他帳號資料。
- [ ] 重新登入或重啟 FastAPI 後，進入 Settings → 題目管理完成一次儲存驗收。

## 安全原則

- Supabase Secret 永遠只存在後端。
- 管理員判斷只在後端完成，不能相信前端傳來的角色名稱。
- 顯示「題目管理」選單不代表取得管理權限；所有完整題目讀取與寫入動作仍須通過 FastAPI UUID 白名單。
- 隱藏測資不會出現在一般題目 API、Run、Judge 結果或前端公開資料。
- 第一版不提供永久刪除已有 Submission 的題目；改用取消發布，避免破壞歷史資料。
