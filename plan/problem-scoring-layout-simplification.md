# 題目測資與計分版面化簡計畫

## 目標

消除題目頁「限制」與「測資與計分」重複顯示的群組條件，將正式測資、配分、執行時間與記憶體限制集中在單一區塊；同步調整管理員新增與修改題目的表單。

## 目前狀態

- [x] 公開題目頁的「限制」與「測資與計分」都會顯示相同配分群組，造成內容重複。
- [x] 執行時間與記憶體限制目前放在獨立的「限制」區塊。
- [x] 管理員表單同時維護獨立限制條件與配分群組得分條件。
- [x] Judge 必須保留配分群組、分數、得分條件與隱藏測資，不能刪除資料結構。

## 執行步驟

- [x] 1. 公開題目頁刪除獨立「限制」區塊，只保留單一「測資與計分」。
  - 簡易說明：同一組條件只顯示一次，縮短題目頁長度。
- [x] 2. 將執行時間與記憶體限制移入「測資與計分」。
  - 簡易說明：所有 Judge 相關規格集中在一起，更容易查找。
- [x] 3. 將 `子任務 1`、`配分群組 1` 等標示統一為「第一組、第二組……」，英文使用 `Group 1`。
  - 簡易說明：統一公開頁、群組選單與管理員表單的用詞，支援最多二十組。
- [x] 4. 管理員新增／修改表單移除獨立限制條件，並把時間與記憶體欄位移入配分群組區。
  - 簡易說明：管理員只需在每組「得分條件」維護一次限制內容。
- [x] 5. 新題目與更新題目不再儲存舊的獨立限制內容，自動測資生成改讀取各組得分條件。
  - 簡易說明：保留資料庫欄位相容性，但新儲存內容固定使用空陣列，不需要破壞性 migration。
- [x] 6. 執行 lint、TypeScript、production build 與題目管理後端測試。
  - 簡易說明：確認版面化簡沒有破壞題目儲存、發布與 Judge 配分。

## 驗收方式

- 每一題左側只出現一次配分群組條件。
- 「測資與計分」同時顯示正式測資數、各組比例、執行時間及記憶體限制。
- 中文依序顯示第一組至第二十組；英文顯示 Group 1 至 Group 20。
- 管理員新增與修改題目時，不再看到獨立限制條件欄位。
- 管理員仍可設定得分條件、配分、隱藏測資、時間與記憶體限制。
- 舊題目載入正常；重新儲存後獨立限制內容清空。

## 需要使用者手動操作的事項

- [ ] 實作完成後開啟任一題目，確認左側版面密度與資訊順序。
- [ ] 分別開啟管理員的新增題目與修改題目，確認欄位位置與群組名稱符合預期。
