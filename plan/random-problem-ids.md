# 隨機題目編號計畫

- 文件狀態：相容程式已部署，等待使用者手動執行 Supabase migration
- 建立日期：2026-09-03
- 格式：一個小寫英文字母加三位數字，例如 `q482`、`a007`

## 目標

讓所有題目使用自動產生的四碼題號。管理員新增題目時不再輸入題號，由後端安全產生並處理碰撞；既有題目則由 Supabase migration 在保留關聯資料的前提下轉換。

## 驗收方式

1. 新題目不需要手動輸入題號。
2. 每個新題號都符合 `^[a-z][0-9]{3}$`。
3. 模擬題號碰撞時會重新產生，不修改原題。
4. 既有題目的測資、作答、草稿與生成版本在換號後仍指向正確題目。
5. 舊題號不再出現在正式題目列表，舊瀏覽器狀態可以轉移。
6. 完整測試與正式建置通過。

## 需要使用者手動操作

- 核可 migration 唯讀內容後，在 Supabase SQL Editor 執行 migration。
- 執行後確認五個既有題目的新題號與內容。
- 在 Supabase SQL Editor 執行 migration 後通知開發端驗證。
