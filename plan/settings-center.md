# Code Tutor 設定中心計畫

- 文件狀態：主要設定中心完成，等待使用者驗收；部署相依功能另列待辦
- 建立日期：2026-08-09
- 目前階段：以完整設定頁取代「關於我們」

## 一、目標

移除頂端「關於我們」，改成可實際操作的「設定」頁。設定頁包含使用者提供圖片中的所有分類，並將原本右上角彈出式 Groq 設定整合進同一頁面。

設定應清楚區分「立即生效的偏好」、「需要登入的帳號操作」與「需要後端管理權限的危險操作」，不能只做看起來可用但實際沒有作用的假按鈕。

- [x] 編輯器目前固定使用字體大小 14、Tab 4、Word Wrap 關閉。
- [x] 介面語言支援繁體中文與英文。

## 四、驗收方式

1. 頂端不再顯示「關於我們」，改為「設定」。
2. 設定頁可以看到圖片列出的全部分類，並額外包含 AI / Groq。
3. 修改 Editor 字體大小、Tab、Word Wrap 或字體後，Project 編輯器會套用。
4. 修改 Console 高度或側欄寬度後，Project 版面會套用。
5. Groq 可以查看狀態、連接、更換與移除。
6. 登入後可以更新個人資料、Email、密碼，並能確認全域登出。
7. 未完成的簡體中文或帳號刪除後端若尚不可用，畫面必須明確標示，不得假裝成功。
