## 一、目標

使用者目前不容易知道網站有哪些限制、資料存在哪裡、題目怎麼計分。本計畫把「注意事項」清楚標示給使用者，分成兩個層級（已與使用者確認範圍為 B 與 C）：

- **B. 網站使用須知**：獨立頁面，說明資料保存、程式執行環境與限制、AI 導師、題目來源與版權。
- **C. 題目頁作答注意事項**：每一題的題目頁加入「作答注意事項」，說明 Run 與 Submit 的差別、入口檔、輸出比對、計分與頻率限制。

同時確立題目內容原則（已與使用者確認）：題目以原創或「用自己的話重新撰寫並更換情境」的方式製作，隱藏測資由本站自行產生，不複製其他網站的題目文字、圖片、範例與測資；並在使用須知與題目頁標示「與 APCS 或其他刷題網站沒有官方關係」。

簡易說明：讓使用者在寫程式前就知道規則，不必靠踩雷學習；同時把題目來源的立場公開寫清楚。
