# Code Tutor 檔案導覽與題目標籤計畫

- 文件狀態：中英文介面完成，等待使用者確認
- 最後更新：2026-08-09
- 目前階段：自動驗收完成

## 一、目標

將頂端的「工作區」改為依語言顯示的「檔案」或 `File`，把主要導覽置中並新增「題目」入口。使用者進入檔案頁時先看到專案與資料夾管理畫面，只有選擇或建立專案後才顯示程式編輯器。題目頁提供容易辨識的標籤，協助使用者快速判斷題目程度與演算法類型。

## 二、目前狀態

- [x] Monaco Editor 與 Online Compiler 已可使用。
- [x] 頂端已有首頁、工作區、測驗與關於我們的靜態按鈕。
- [x] 導覽按鈕可以切換實際內容。
- [x] 檔案頁先顯示專案與資料夾，不會直接載入程式編輯器。
- [x] 已建立題目列表、搜尋與標籤介面。

## 三、執行步驟與簡易說明

### 1. 調整頂端導覽

- [x] 將「工作區」改成中文「檔案」、英文 `File`。
- [x] 在檔案與測驗之間增加「題目」。
- [x] 使用左右等寬配置，讓主要標籤位於頁面中央。
- [x] 讓檔案與題目按鈕可以切換內容及目前選取狀態。

簡易說明：導覽列是網站的目錄。置中後主要功能比較容易被找到，使用者也能清楚知道目前在哪個頁面。

### 2. 建立檔案首頁

- [x] 進入檔案頁時不自動顯示程式編輯器。
- [x] 左上角放置「新增資料夾」。
- [x] 右上角放置「新增專案」。
- [x] 顯示既有專案與資料夾卡片。
- [x] 點擊專案或新增專案後才進入原本的 Compiler 工作畫面。
- [x] 再次點擊頂端「檔案」或 `File` 可以返回檔案首頁。

簡易說明：檔案首頁像是書櫃，先選擇要開啟哪個專案，再進入編輯器，不會一進頁面就被一段範例程式占滿畫面。

### 3. 建立題目與標籤介面

- [x] 建立題目搜尋欄。
- [x] 顯示常用標籤，例如 `#APCS中高級`、`#二分搜`。
- [x] 題目卡片顯示難度、類型與標籤。
- [x] 點擊標籤可以篩選題目。
- [x] 沒有符合項目時顯示清楚的空狀態。

簡易說明：標籤像題目的索引。使用者在開始作答前，就能知道這題適合的程度以及可能使用的解題方法。

### 4. 響應式與驗證

- [x] 桌面版導覽保持真正置中。
- [x] 窄畫面不產生水平溢位，主要操作仍可使用。
- [x] 執行 ESLint 與 Next.js production build。
- [x] 確認原本 Compiler 的 Run 功能沒有被破壞。

簡易說明：除了確認新畫面好看，也要避免修改導覽後讓原本已完成的編譯功能失效。

### 5. 繁體中文與英文切換

- [x] 建立全站共用的語言狀態與翻譯文字。
- [x] 繁體中文導覽顯示「檔案」，英文導覽顯示 `File`。
- [x] 右上語言按鈕開啟下拉選單，再選擇繁體中文或 `English`。
- [x] 語言按鈕與選單不顯示「中」或 `EN` 前綴。
- [x] 設定旁以框外「語言」搭配框內「繁體中文」顯示；英文為框外 `Language`、框內 `English`。
- [x] 使用者的專案名稱不會因介面語言切換而改變。
- [x] 翻譯首頁、檔案頁、題目頁、History、AI Tutor、編輯器與輸出提示。
- [x] 將語言選擇保存在瀏覽器，重新整理後繼續使用原語言。
- [x] 切換時同步更新 HTML `lang`，協助瀏覽器與輔助工具判斷語言。
- [x] 分別驗證中英文桌面與手機畫面。

簡易說明：畫面只顯示目前選擇的語言，不會把「檔案」和「File」同時放在按鈕中。共用翻譯系統也能避免未來新增頁面時，每個元件使用不同的切換方式。
